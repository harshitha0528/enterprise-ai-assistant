# Enterprise AI Assistant

An AI-powered enterprise assistant that helps employees understand company documents and investigate technical incidents using Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and AI Agents.

## Key Modules

### 1. Document Intelligence
- Upload company documents.
- Ask questions about uploaded documents.
- Retrieve relevant information using RAG.
- Generate answers with source references.

### 2. Incident Intelligence
- Upload application logs.
- Identify repeated errors.
- Investigate possible causes.
- Generate incident reports.

## Technology Stack

- Python
- FastAPI
- OpenAI API
- LangChain
- LangGraph
- ChromaDB
- PostgreSQL
- React
